Pengaturan workspace

Koneksi Google Sheets

Gunakan spreadsheet baru dengan Code.gs DAW Finance v4. Cukup tempel URL Web App /exec; koneksi tersimpan di perangkat ini.

Hubungkan spreadsheet terlebih dahulu. Setelah terhubung, salinan data juga disimpan di perangkat.

Tinjau perbedaan data

Perubahan pada item yang sama perlu ditinjau. Unduh backup lokal, muat data cloud terbaru, lalu terapkan kembali koreksi Anda. Impor backup tidak menimpa ID yang sudah ada.

Cadangan & portabilitas

Backup JSON mencakup semua transaksi, daftar proyek, dan riwayat penutupan. Ekspor CSV mengikuti filter aktif. Impor menambahkan transaksi dengan ID baru; ID yang sudah ada dilewati.

Pintasan: N transaksi baru · / cari · Esc tutup. Animasi mengikuti pengaturan gerakan perangkat.
